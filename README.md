# Movie Ticket Booking System 🎬

A beginner-friendly movie ticket booking system built using Python and Object-Oriented Programming (OOP).

## 📌 Features

- Store movie information
- Set total number of seats
- Set ticket price
- Book multiple tickets
- Check seat availability
- Display booking status
- Calculate total ticket price
- Validate invalid ticket quantities
- Prevent invalid seat counts and ticket prices

## 🛠️ Concepts Used

- Python
- Classes and Objects
- Object-Oriented Programming (OOP)
- Constructors
- Instance Attributes
- Methods
- Type Hints
- Conditional Statements
- Input Validation
- Exception Handling
- Basic State Management
